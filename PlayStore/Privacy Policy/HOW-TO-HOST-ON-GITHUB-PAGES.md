# Host the Privacy Policy on GitHub Pages (free)

You need a public URL for Play Console. Steps:

1. Create a new PUBLIC GitHub repo, e.g. deathink-privacy.
2. Upload the file index.html from this folder to the repo root (keep the name index.html).
3. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder /root > Save.
4. Wait about 1 minute. Your URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/deathink-privacy/
5. Open it to confirm it loads, then paste that URL into:
   - Play Console > Store listing > Privacy policy
   - Play Console > App content > Data safety
6. Record the final URL in PlayStore/Notes/Website.txt.
