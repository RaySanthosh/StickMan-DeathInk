# Phone Screenshots - capture guide

Google Play needs 2-8 phone screenshots. Recommended: 8.

## Required specs
- Format: PNG (24-bit, no alpha) or JPEG
- Aspect: landscape 16:9 (this game is landscape)
- Recommended size: 1920 x 1080 px (min side 320, max side 3840)
- All screenshots should be the SAME size.

## How to capture
1. Install the release build on a phone:  flutter install --release
   (or build an APK:  flutter build apk --release  and copy it over)
2. Play the game and take a screenshot at each scene below.
3. On most Androids: Power + Volume Down.
4. Copy the PNGs into this folder named Screenshot-1.png ... Screenshot-8.png
5. If a phone screenshot is not exactly 1920x1080, that is fine as long as it is
   16:9 and at least 320px on the short side.

## Suggested 8 shots (show variety + selling points)
1. Title screen (Death Ink logo)
2. Early gameplay - stickman running/jumping
3. A deadly trap moment (spikes or darts about to hit)
4. A death + a sarcastic taunt on screen
5. The death-note / notebook screen (death log)
6. Level select / chapter map
7. The global leaderboard
8. A chapter-clear / star rating screen

Tip: turn the phone to landscape and hide the status bar if possible for cleaner shots.
